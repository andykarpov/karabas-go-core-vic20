# Ядро Commodore VIC-20 для Karabas Go / Mini / Mini G

[English version](README.md)

Commodore VIC-20 (6502, VIC 6561 / 6560, дисковод 1541, магнитофон, расширения памяти, картриджи, Mega-Cart) для плат семейства Karabas Go (Xilinx Spartan-6 XC6SLX25): порт [VIC20Nano](https://github.com/MiSTle-Dev/VIC20Nano) (VIC-20 MiST / MiSTer от MikeJ и WoS, C1541 от darfpga).

Состояние: в работе (см. `docs/PLAN.md`). На плате пока ничего не запускается.
