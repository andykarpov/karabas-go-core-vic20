# Commodore VIC-20 core for Karabas Go / Mini / Mini G

[Русская версия](README.ru.md)

Commodore VIC-20 (6502, VIC 6561 / 6560, 1541 disk drive, datasette, RAM expansions, cartridges, Mega-Cart) for the Karabas Go board family (Xilinx Spartan-6 XC6SLX25): a port of [VIC20Nano](https://github.com/MiSTle-Dev/VIC20Nano) (the MiST / MiSTer VIC-20 of MikeJ and WoS, the C1541 of darfpga).

Status: work in progress (see `docs/PLAN.md`, in Russian). Nothing runs on a board yet.
